# Changelog

## 1.1.0 - 2026-08-09

### Added
- Added a redesigned CodeX Seller admin dashboard.
- Added separate admin views for Dashboard, Updates, Backups, Reports, and Settings.
- Added safe update flow with health checks, backup before update, rollback support, and email reports.
- Added manual "Run Now" update action and scheduled automatic updates.
- Added product filters for all products, plugins, and themes.
- Added backup history and latest backup rollback controls.
- Added fixed API Base URL display for `https://codexsell.com/`.

### Changed
- Settings now opens as a dedicated page from the sidebar.
- API Base URL is fixed and no longer editable from the admin UI.
- Dashboard and update page layouts were simplified by removing the Credits widgets.

### Fixed
- Improved admin navigation so each sidebar option opens its own page.
- Improved responsive admin layout for smaller screens.

## 1.0.0 - 2026-07-11

### Added
- Initial CodeX Seller plugin release.
- Added account settings for API connection.
- Added purchased product fetch action.
- Added plugin/theme install and update support from CodeX Seller downloads.
